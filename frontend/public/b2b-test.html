📋 Hazır Embed Kodları

Bu kodları kendi web sitenize kopyalayarak AI Sınav Sistemi'ni gömebilirsiniz.

Yöntem 1 — Basit iframe Embed
<iframe
  src="http://localhost:5173"
  width="100%"
  height="700"
  allow="camera; microphone; display-capture"
  style="border: none; border-radius: 12px;"
></iframe>
Yöntem 2 — Floating Widget (Sabit Köşe)
<iframe
  src="http://localhost:5173/?examCode=YOUR_CODE"
  width="400"
  height="600"
  allow="camera; microphone; display-capture"
  style="border: none; position: fixed; bottom: 20px;
    right: 20px; z-index: 9999; border-radius: 12px;
    box-shadow: 0 8px 32px rgba(0,0,0,0.3);"
></iframe>
Yöntem 3 — postMessage ile Haberleşme
// Parent sayfa: iframe'den gelen mesajları dinle
window.addEventListener('message', (event) => {
  if (event.data?.type === 'PROCTOR_EVENT') {
    console.log('Sınav olayı:', event.data);
    // { type: 'PROCTOR_EVENT', event: 'exam-started' | 'violation' | 'exam-completed', data: {...} }
  }
});

// iframe'e komut gönder
const iframe = document.getElementById('proctor-frame');
iframe.contentWindow.postMessage({
  type: 'PROCTOR_COMMAND',
  command: 'set-exam-code',
  data: { examCode: 'ABC123' }
}, '*');
