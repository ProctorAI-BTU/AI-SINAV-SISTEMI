ProctorSDK

Tek satır kod ile gerçek zamanlı AI sınav gözetimini kendi platformunuza entegre edin.

🔑 API Key Auth 📡 WebSocket 🤖 AI Analysis 🪝 Webhook 🎨 Özelleştirilebilir 🌍 TR / EN

⚡ 2 Adımda Entegrasyon

Kendi web sitenize 2 dakikada ekleyin.

Adım 1 — Script'i Ekle
<!-- HTML <head> veya <body> sonuna ekleyin -->
<script src="https://platform.com/sdk/proctoring-widget.js"></script>

<!-- İsteğe bağlı: Widget'ı belirli bir div'e yerleştir -->
<div id="proctor-container"></div>
Adım 2 — Widget'ı Başlat
ProctorSDK.init({
  apiKey:     'pk_live_xxxxxxxxxxxx',
  gatewayUrl: 'https://platform.com',
  examId:     'EXAM-2026-001',
  studentId:  'STU-12345',

  onReady: (session) => {
    console.log('Sınav başladı:', session.sessionId);
  },
  onComplete: (report) => {
    // Kendi API'nize gönderin
    fetch('/api/submit', {
      method: 'POST',
      body: JSON.stringify(report)
    });
  },
  onViolation: (event) => {
    console.warn('İhlal:', event.eventType);
  },

  options: {
    primaryColor: '#6366f1',
    language:     'tr',
    showOverlay:  true,
    containerId:  'proctor-container',
  }
});

Tüm yapılandırma seçenekleri ve metodlar.

⚙️ Yapılandırma Seçenekleri

apiKey:         string   // *Zorunlu
gatewayUrl:     string   // *Zorunlu
examId:         string   // *Zorunlu
studentId:      string   // *Zorunlu
studentName:    string   // Opsiyonel
onReady:        function // (session) => void
onComplete:     function // (report) => void
onViolation:    function // (event) => void
onError:        function // (message) => void

options.primaryColor:   '#6366f1'
options.language:       'tr' | 'en'
options.showOverlay:    true
options.containerId:    'proctor-container'
options.logoUrl:        string | null
options.frameIntervalMs: 3000
options.audioIntervalMs: 5000

🔧 Metodlar

// Widget başlat
ProctorSDK.init(config) → ProctorWidget

// Sınavı programatik olarak bitir
ProctorSDK.endExam()

// Risk skorunu al
ProctorSDK.getRiskScore()
// → { score: 23, level: 'LOW' }

// Widget'ı temizle
ProctorSDK.destroy()

// Versiyon
ProctorSDK.version // '1.0.0'
